# Dataset Studio and scientific limitations

ResearchForge Dataset Studio supports uploaded tabular data, deterministic synthetic generation, approved statistical analyses, and publication-oriented figures/tables.

## Provenance types (strict)

Every dataset carries exactly one `provenance_type`:

| Type                   | Meaning                                             |
| ---------------------- | --------------------------------------------------- |
| `uploaded_real`        | User-uploaded CSV/XLSX treated as real data         |
| `publicly_sourced`     | Declared public source (license/source description) |
| `synthetic`            | Generated by ResearchForge Python generator         |
| `simulated_experiment` | Simulated experiment output                         |
| `calculated_result`    | Derived numeric/statistical output                  |
| `user_entered`         | Manually entered values                             |

Synthetic datasets always show:

> Synthetic dataset generated by ResearchForge. It must not be represented as collected experimental data.

This label appears in the UI, exported metadata, reproducibility manifests, figure/table provenance, and manuscript insert warnings. It is **locked** and cannot be removed.

Conceptual diagrams (Mermaid) are labeled **AI-assisted conceptual illustration** and are never mixed with experimental result figures.

## Analysis constraints

- Approved operations only (descriptive stats, correlation, missingness, group comparison, CIs, t-test, Mann–Whitney U, ANOVA, chi-square, simple regression, classification metrics, confusion matrix, ROC, precision–recall).
- **No arbitrary user Python execution** in the initial version.
- The LLM may propose a schema; Python generates and validates synthetic rows.
- Every run stores dataset version, parameters, package versions, seed, code representation, results, warnings, and timestamp.

## Scientific limitations

1. Analyses use approved statistical routines only; they are not a substitute for domain expertise.
2. p-values and confidence intervals assume model conditions that may not hold for your data.
3. Synthetic or simulated inputs must not be reported as collected experimental observations.
4. Classification curves require probability/score columns; binary labels are assumed when applicable.
5. Figures for scientific results require an associated dataset version or completed analysis run.
6. Descriptive profiles and PII-risk heuristics are advisory, not a compliance guarantee.

## Exports

- Figures: high-resolution PNG, SVG, PDF with captions, alt text, source reference, reproducibility metadata.
- Tables: HTML, CSV, DOCX fragment, LaTeX.
