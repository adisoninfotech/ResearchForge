# Guided ethical engagement

ResearchForge helps users complete genuine research work without manipulative engagement patterns (no dark-pattern streaks, fake urgency, or unreliable time promises).

## Project home

Shows weighted paper completion, sections completed, missing evidence, unsupported claims, unverified references, dataset status, figures/tables needed, open similarity findings, target submission date, last saved time, and the next recommended action.

## Completion calculation

Completion is **not** based only on word count. It is a weighted sum (100 points) of:

- Problem / contribution defined
- Evidence attached
- Methodology complete
- Dataset provenance present
- Analysis complete
- Results supported
- Limitations included
- Citations verified
- Figures / tables resolved
- Integrity warnings addressed
- Required journal statements complete

Progress events explain why the score changed.

## Guided questions

Contextual questions (dataset, baselines, metrics, significance, real/synthetic/simulated, limitations, ethics) save as structured project facts. AI prompts receive missing facts as an explicit placeholder and must not invent values.

## Daily goals & milestones

Users pick a daily focus (section, references, analysis, similarity, figures, export) and receive a short task sequence **without** completion-time estimates.

Milestones mark real research progress (plan approved, dataset added, citations verified, submission package generated, etc.).

## Notifications

User-controlled preferences. Writing reminders remain **off** unless enabled. Supported kinds include draft deletion, trash expiration, export/similarity completion, submission date approaching, weekly summary, and a collaborator-activity placeholder.

## Retention

Retention information is shown on project home with one-click **Keep**, **Archive**, **Export**, and **Delete now**.

## Analytics

Privacy-conscious product events only (account/project created, section completed, export requested, guest draft converted, similarity completed, dataset analyzed). Never includes titles, manuscript text, filenames, citations, or dataset values.

## Accessibility

Project home and preference controls aim for WCAG-conscious keyboard use, labels, contrast, visible focus, reduced-motion support, and accessible progress descriptions.
