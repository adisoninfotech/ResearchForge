# Core product rules

1. Guests may explore the application and generate a limited preview.
2. Guests must not save projects on the server.
3. Guests must not permanently upload documents.
4. Guests must not download complete manuscripts.
5. When a guest clicks Save, Upload, Full Export, Full Similarity Check, or Generate Full Section, display authentication.
6. Preserve a guest’s temporary content in browser storage.
7. After successful login, allow the user to transfer the temporary guest draft into a saved project.
8. Logged-in users receive autosave, project storage, version history, files, datasets, figures, reports, and exports.
9. Export templates are compatible starting templates only—never claim official publisher certification unless licensed/approved. Authors must verify current submission requirements.
10. Engagement must remain ethical: no manipulative patterns, no unreliable completion-time promises, and writing reminders only when enabled.
11. AI must use saved project facts consistently and must not invent missing answers.
12. User content is private by default.
13. User content must not be used for model training unless the user explicitly opts in.
14. Synthetic datasets and simulated results must always be visibly labeled.
15. Never describe the similarity checker as guaranteeing zero plagiarism, plagiarism-free status, guaranteed originality, or equivalence to Turnitin/iThenticate. Prefer: “No significant textual overlap was identified within the sources checked.” Always show coverage limitations and require human review.
